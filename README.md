# Xmas-BINGO_Simulator

クリスマスのビンゴ大会の進行を試す、サーバー不要のシミュレーターです。
このリポジトリには既存アプリがなかったため、READMEのみの状態から実装しました。

## 起動

GitHub Pagesでリポジトリのルートを配信できます（ビルド不要）。
ローカルではこのフォルダーで次を実行し、http://localhost:8000 を開いてください。

```powershell
python -m http.server 8000
```

Web Workerを利用するため、index.htmlの直接起動（file://）ではなくHTTPで開いてください。
外部ライブラリ、外部API、データベースは使用しません。

## カードと抽選

- 5×5、中央は常に数字を持たないFREE。抽選前から開き、縦・横・斜め12列の判定に反映します。
- 球数は75・90のプリセットと任意入力（24〜100,000の整数）。初期値は75球です。
- 列指定ON：連続した範囲に5分割し、余りをB→I→N→G→Oの順で配分します。N列は4数字、ほかは5数字を重複なしで選びます。75球では標準の各15数字です。
- 列指定OFF：全範囲から24数字を重複なしで配置します。
- 24球・列指定ONはO列が4数字しかなく開始できません。OFFなら24球から利用できます。
- 毎試行、全員のカードと1〜設定球数の抽選順を新しくランダム生成します。同じ数字を再抽選しません。
- 全球を引いた後は追加抽選をせず、残り時間を経過させ、制限時間で大会を終了します。

## 進行・当選の計算

抽選間隔が経過するごとに1球を引き、成立列数を判定します。
「当選に必要なビンゴ列数」ごとに1回当選でき、「1人の景品獲得上限」と全体の景品数で制限します。
例：必要2列・上限3個なら、2・4・6列成立で各1個を獲得できます。
同じ抽選で複数の当選機会が生まれた場合、授与順はランダムです。
景品1個ごとに進行時間を消費し、受け渡し中は抽選を止めます。
制限時間内に受け渡しを完了できるものだけを当選として数えます。
当選人数は1個以上獲得した人数、当選回数と景品獲得数は授与した個数です。
景品がなくなっても、制限時間までは抽選を続けます（全球終了時を除く）。

高速計算はWeb Workerで指定回数を実行し、平均・最小・最大を表示します。
キャンセルはWorkerを終了し、途中結果は保存しません。
アニメーションは同じ計算エンジンの1試行を再生します。速度は表示上の速度で、シミュレーション時間には影響しません。
一時停止・再開と、表示する参加者の切替に対応しています。

## 履歴

完了した計算の設定と集計結果をlocalStorageに最新100件まで保存します。
球数と列指定ON/OFFを含む詳細表示、設定読込、複数履歴の比較ができます。
履歴は同じブラウザー・配信元で保持されます。カードや乱数シードは保存しないため、設定を読み込んだ再実行では新しい乱数による結果になります。
旧形式で球数・列指定がない場合は75球・列指定ONとして補完します。
このリポジトリには旧アプリがなかったため、別アプリ固有の履歴キーへの移行は行っていません。
テーマもlocalStorageで保持します。

## テスト

Node.js（外部パッケージ不要）：

```powershell
npm test
```

ChromeとPythonがあるWindows環境でのブラウザー結合テスト：

```powershell
python tests/browser_check.py
```

一時HTTPサーバーと専用の一時Chromeプロファイルでテストし、通常のブラウザー履歴には触れません。
Chromeの場所が異なる場合はbrowser_check.pyの実行ファイルパスを変更してください。

## ファイル

- index.html / style.css：設定・結果・再生・履歴画面、ライト／ダークテーマ、小画面対応
- engine.js：カード生成・入力検証・抽選・ビンゴ判定・当選計算・集計の共通処理
- worker.js：高速試行、進捗通知
- history.js：履歴保存・読込・設定補完
- app.js：画面操作、再生、Workerの開始・キャンセル、履歴の詳細・比較・設定復元
- tests/：計算・Worker・履歴の自動テスト、実ブラウザーの操作テスト

公開用リポジトリです。公開前の開発履歴は含めていません。
